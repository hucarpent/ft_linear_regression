# ft_linear_regression

A 42 project implementing univariate linear regression from scratch to predict car prices based on mileage.

## How it works

The model learns a linear relationship `price = intercept + slope * mileage` using gradient descent. Parameters are iteratively updated until convergence, then saved to `estimation.csv` for use by the estimator.

## Usage

**Train the model:**
```bash
python3 train.py
```
Trains on `data.csv`, prints model precision, plots the regression line, and writes `estimation.csv`.

```bash
python3 train.py -p
```
Trains and prints precision only (no plot).

**Estimate a price:**
```bash
python3 estimate.py <mileage>
```
Reads `estimation.csv` and outputs the predicted price for the given mileage. Requires training first.

## Files

| File | Description |
|------|-------------|
| `train.py` | Gradient descent training loop |
| `estimate.py` | Price estimator using saved parameters |
| `data.csv` | Training data (mileage, price pairs) |
| `estimation.csv` | Saved model parameters (generated by training) |

## Requirements

- Python 3
- matplotlib
